# 금집부쌤의 서울시 아파트 실거래 대시보드

서울시 25개 자치구 아파트 매매/전월세 실거래를 구·동 단위로 조회하는 대시보드.
"반포114" 서초구 대시보드(`../banpo dashboard`)와 같은 구조(파이썬 stdlib 서버 + 순수 JS 프론트)를
서울 전역으로 확장한 별도 프로젝트입니다.

## 실행

```
python server.py          # 또는 실행하기.bat 더블클릭
```

기본 포트는 **8766** 입니다(반포114 대시보드가 8765를 쓰므로 동시 실행 가능).

## 사용하는 API 4종

| API | 용도 | 비고 |
|---|---|---|
| 국토교통부 실거래가(data.go.kr) | 아파트 매매/전월세 원본 | 25개 구 각각 LAWD_CD로 조회 |
| 카카오(dapi.kakao.com) | 지도 표시 + 지오코딩 | JS 키는 브라우저용, REST 키는 서버 전용 |
| 서울 열린데이터광장 | 공원·상권(입지분석) | 별도 승인 없이 즉시 사용 가능한 일반 키 |
| KOSIS 국가통계포털 | 구별 인구·세대·고령화 + **한국부동산원 공동주택 실거래가격지수**(구 단위·분기별) | REB 지수는 KOSIS가 유통하는 자료(ORG_ID=408)로 확인, 별도 R-ONE 키 불필요 |

## 지역 필터 구조

**구 선택 → 그 구의 법정동만 동적으로 표시.** 8개 동만 있던 서초구 버전과 달리 서울 전역
467개 법정동을 하드코딩할 수 없어, 서버가 내려준 데이터에 실제로 등장한 동만 필터 버튼으로 만듭니다.
"전체 서울(25개 구 합산)"도 선택 가능하지만 최초 조회 시 25개 구를 전부 훑어야 해서 느릴 수 있습니다
(캐시된 이후에는 빠릅니다).

## 지도

서초구 버전과 달리 **폴리곤 개략도 폴백이 없습니다** — 467개 동의 실제 모양을 손으로 그리는 건
비현실적이라, 카카오맵만 사용합니다. 카카오맵 JS SDK는 **등록된 도메인에서만** 동작하므로,
카카오 개발자센터(반포114 때 만든 앱을 그대로 재사용) → 플랫폼 키 → JavaScript 키 → 수정 →
JavaScript SDK 도메인에 `http://localhost:8766` 을 추가로 등록해야 지도가 뜹니다.
도메인이 등록되지 않았거나 인터넷이 안 되면 지도 대신 안내 문구만 표시됩니다(페이지가 깨지지 않음).

좌표는 `geocode_build.py`로 미리 구해 `web/geo-coords.js`에 저장해 둡니다(키 형식: `구|동|단지명`).
서울 전역이라 단지 수가 수천 개 단위가 될 수 있어 최초 실행에 시간이 좀 걸립니다. 이후 재실행 시
새로 나타난 단지만 추가로 조회합니다.

## 입지분석

기존 서초구 버전은 반포·잠원·서초·방배 4개 동만 사람이 직접 쓴 편집 데이터였습니다. 이번 버전은
**"생활권·인구"** 탭에 서울 열린데이터광장(공원·상권)과 KOSIS(인구·세대·고령인구비율) **실데이터**를
25개 구 전체에 대해 자동으로 보여줍니다. 지하철·교통·학군·재건축은 신뢰할 수 있는 구·동 단위 공개
데이터를 아직 연결하지 못해 "추후 제공 예정"으로 남겨뒀습니다(허위로 채워 넣지 않음).

## 한국부동산원 공식 지수

가격지수 차트에서 "공식(부동산원) 지수 비교" 버튼을 누르면 KOSIS를 통해 유통되는 한국부동산원
**공동주택 매매 실거래가격지수**(구 단위, 분기별, 2017년 4분기=100)를 함께 볼 수 있습니다. 기존 자체
산출 지수(동 단위까지 가능, 주간/월간)와는 산출 방식·단위(분기 vs 주/월)가 다르므로 참고용 비교선으로
제공합니다. 전체 서울(`gu=all`) 선택 시에는 구 단위 통계라 표시하지 않습니다.

## 알려진 한계

- REST/JS 카카오 키, 서울 열린데이터광장 키, KOSIS 키가 모두 `server.py`에 평문 상수로 들어 있습니다
  (반포114 프로젝트와 동일한 패턴 — 로컬 실행 전용이라 배포 시 환경변수로 옮기는 걸 권장합니다).
- "전체 서울" 합산 모드는 TOP10/평당가/상승률 계산에 25개 구 데이터를 그대로 섞어 씁니다 — 구별
  비교가 필요하면 구를 하나씩 선택해서 보는 편이 더 명확합니다.
- GitHub Pages 등 정적 호스팅 배포용으로 `build_static.py`가 있습니다 — 25개 구 실거래·입지분석·
  공식지수를 스냅샷으로 구워 `docs/` 폴더를 만듭니다(자세한 내용은 `DEPLOY.md` 참고). 정적 스냅샷은
  빌드 시점 데이터로 고정되며, 실시간 조회가 아닙니다.
